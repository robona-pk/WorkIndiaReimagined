# WorkIndia Reimagined

An interactive prototype of a rethought employer trial experience for WorkIndia's hunting (employer acquisition) product, built from:

- analysis of 12,541 employer sales calls
- a cohort study of 98,505 employers (visit × response × unlock behaviour)
- the Agent-Driven NN Activation (ANN) PRD and pilot data
- first-week employer interviews
- a live walkthrough of the production employer flow on workindia.in (including one reproduced bug)

## View it

Open `index.html` directly, or enable GitHub Pages on this repo (Settings → Pages → Deploy from branch → `main` / root) for a live URL.

## What's inside

A single-page site: the evidence behind the rethink, a six-step interactive walkthrough of the redesigned trial (AI-screened candidates, platform-only calling, outcome-based trial end, a post-hire feedback loop), and a today-vs-reimagined comparison table with open parameters flagged as open, not decided.

No build step — plain HTML/CSS/JS, no dependencies.
